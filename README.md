# Biogate
Python-based software to simulate both silicon-based and cell-based (biological) logic gates, comparing energy usage and calculation time.

## Linux (x86_64)

1. Open the [GitHub Releases](https://github.com/alexanderwdougherty/biogate/releases) page and download `Biogate-linux-x86_64.tar.gz`
2. Extract the archive using your file manager
3. Open a terminal in the extracted folder—the folder containing the `Biogate` directory—and run:

   ```bash
   chmod +x Biogate/Biogate
   ./Biogate/Biogate
   ```
